One line, at most 200 characters: the single sentence that could have replaced an entire pointless meeting. The program writes the line to `output/entry.txt` — no context, no explanation, just the line that kills the meeting.

## Run

```sh
node main.ts
```

This writes the entry to `output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when set), with no trailing newline.
